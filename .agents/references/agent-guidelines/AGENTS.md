This is a repository meant to be read by agents and provide generic
guidelines for agentic aided work.

Not all of it is meant to be used for all projects and it is organized
such that it can be referenced independently.

See the [contributing](./contributing/) directory for roles and workflows to run.

The file [agents_md_template.md](./agents_md_template.md) is a pre-generated context to put into your projects.

The [summaries](./summaries) folder contains compacted summaries of externally referenced resources. Check here before reading the referenced resource.
